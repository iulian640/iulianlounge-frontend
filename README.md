# IulianLounge — Frontend

Speakeasy virtual navegable en 3D. Three.js + Vue + Vite.

El concepto y la arquitectura del proyecto viven en el repo
[iulianlounge-backend](https://github.com/iulian640/iulianlounge-backend)
(`CONCEPT.md` y `docs/architecture.md`).

> En construcción. La escena 3D (Three.js WebGPU) avanza en la rama [`feature/webgpu`](https://github.com/iulian640/iulianlounge-frontend/tree/feature/webgpu); `main` recibe el código al cerrar cada sprint. Entrega prevista: octubre de 2026.
